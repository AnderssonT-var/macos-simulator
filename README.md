# macOS Simulator

Recreación de un escritorio de macOS en el navegador, hecha con React.

**Demo en vivo:** [enfoco.media](https://enfoco.media)

## Funciones

- Pantalla de arranque y escritorio con iconos
- Ventanas que se pueden arrastrar, abrir y cerrar
- Barra de menú con Centro de control, Centro de notificaciones, batería y calendario
- Mini reproductor de música
- Aplicaciones: Calendario, Música, Carpetas, Directorio, Servicios y un juego
- Ajustes del sistema con cambio de fondo de pantalla

## Tecnologías

React 19 · Vite · CSS · react-draggable · react-calendar · react-icons

## Ejecutar en local

```bash
npm install
npm run dev
```

Para generar la versión de producción: `npm run build`.
